SOULSIDE — Android PWA prototype

Содержимое:
- index.html — интерфейс и демонстрационные функции
- manifest.webmanifest — настройки установки как приложения
- sw.js — базовый service worker для кеширования

Как проверить:
1. Распакуйте архив.
2. Разместите файлы на HTTPS-хостинге (или запустите локальный сервер для теста).
3. Откройте ссылку в Chrome на TECNO Spark.
4. В меню Chrome выберите «Установить приложение» или «Добавить на главный экран».

Важно:
- Это прототип интерфейса. Переписка пока использует демонстрационные ответы, а не подключённую ИИ-модель.
- Данные хранятся локально в браузере; очистка данных сайта может удалить их.
- Для установки PWA нужен HTTPS (кроме localhost).
- Для настоящих фоновых уведомлений, синхронизации и ИИ нужен backend.
- Не добавляйте секретные API-ключи в index.html или другой клиентский код.
