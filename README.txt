# SOULSIDE — первая социальная версия

## Файлы
- `index.html` — приложение: Twitter-лента, Telegram-чаты и каналы, профили, фото, события и сцены.
- `manifest.webmanifest` — настройки установки как PWA.
- `sw.js` — базовое кеширование.

## Публикация
Загрузите ВСЕ три файла в корень существующего GitHub-репозитория и включите GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).
После публикации откройте сайт в Chrome на Android и выберите «Установить приложение».

## Что работает в этой версии
- Лента с тестовыми персонажами и вымышленными пользователями.
- Создание постов, лайки, комментарии и репосты.
- Загрузка фотографии к посту.
- Telegram: демонстрационные личные чаты и отдельные каналы персонажей.
- Редактирование единого профиля (имя, ник, описание, аватар).
- Галерея фотографий.
- Случайные события, пока приложение открыто; часть событий открывает текстовую интерактивную сцену.
- Локальное сохранение постов, переписок и профиля в браузере.

## Важные ограничения
Это локальный прототип: ответы персонажей пока шаблонные, а публикации и события не генерируются настоящей ИИ-моделью. Случайные события появляются только при открытом приложении. Для фоновой активности, общей синхронизации между устройствами и настоящей памяти персонажей нужен сервер и база данных.
Изображения сохраняются локально и могут занимать место. Очистка данных сайта может удалить локальные данные.
Сцены в этом прототипе рассчитаны на дружеские встречи, совместные занятия и приключения.
